# General automation scripts

Bash, PowerShell and Ansible examples. Each project has different privileges, target systems and maturity; inspect its own documentation before use.

| Directory | Purpose |
|---|---|
| [bitnami_renew_cert](bitnami_renew_cert/) | Historical Bitnami certificate automation |
| [cloudflare](cloudflare/) | DNS and dynamic DNS examples |
| [custom-win-iso](custom-win-iso/) | Destructive Windows installation lab template |
| [geolocation](geolocation/) | IP/location lookup utilities |
| [install_docker_ce](install_docker_ce/) / [install_docker_centos](install_docker_centos/) | Distribution-specific Docker installation examples |
| [node-exporter](node-exporter/) | Monitoring exporter automation |
| [openvpn](openvpn/) | VPN installation and location switching |
| [proxmox](proxmox/) | Proxmox automation |
| [rhel_config_ftp_repo](rhel_config_ftp_repo/) | Repository configuration |
| [sign_vmware_modules](sign_vmware_modules/) | VMware module-signing examples |
| [zabbix](zabbix/) | Monitoring examples |

Use private runtime credentials and isolated lab fixtures. Older product/version examples are historical until retested. No blanket production readiness or successful deployment is claimed.
